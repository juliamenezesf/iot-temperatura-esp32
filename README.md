# Projeto IoT - Monitoramento de Temperatura

Projeto utilizando ESP32 + DHT22 + MQTT + Node-RED

## Funcionalidades
- Leitura de temperatura e umidade
- Envio via MQTT
- Dashboard em Node-RED
- Integração com API externa

## Simulação
Executado no Wokwi

## Tecnologias
- ESP32
- MQTT (HiveMQ)
- Node-RED
- OpenWeather API
